# Product problem

Autotest Skill gives coding agents an evidence-based way to verify web applications, API services, Telegram bots and supported native applications. It reduces repetitive setup, exploratory navigation, reproduction and reporting work.

The first release must find broken user flows, incorrect API results, access-control regressions, bot-state leakage and actionable interface problems. An HTTP 200, a running process or a successful click alone is insufficient evidence.

The agent discovers the repository, proposes checks tied to explicit expectations, executes actual tools, repeats suspected failures and exports both machine-readable results and reproducible evidence. Existing repository tests are preferred.

The product does not promise complete bug discovery or replace requirements, human product judgment or a dedicated security audit. Application changes and publication require authorization separate from running checks.
