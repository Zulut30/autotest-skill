# Repository layout

- SKILL.md: agent workflow.
- src/autotest_skill/: deterministic CLI and adapter implementation.
- references/: focused instructions for agents.
- examples/: executable, secret-free configurations.
- fixtures/: isolated targets with known defects and clean controls.
- tests/: behavioral verification of the tool itself.
- scripts/: repeatable installation and demonstration commands.
- docs/: requirements, runtime evidence and presentation materials.

Generated output stays in ignored directories. Credentials are never committed.
