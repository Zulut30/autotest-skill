# First release scope

Required: skill instructions; Python CLI; validated YAML configuration; existing-test execution; HTTP assertions; Playwright flows; aiogram handler checks; a Telethon live-client adapter; Android adapter for an external Appium runner; performance and security adapters; structured and readable reports; examples and CI.

Required evidence before claiming complete: executed web/API scenarios, executed local bot scenarios, a genuine Telegram-client flow, and an Android flow on a compatible device or emulator. A transport simulator is labeled as such.

Non-goals for this release: iOS and desktop support, production load testing, payments or mass messaging, arbitrary autonomous code publication, and guaranteed replacement of human QA. Automatic fixes are proposals with explicit regression tests, not a default behavior.
