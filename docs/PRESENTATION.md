# Сценарий презентации: 13 минут

Это презентация проверенной **alpha 0.1.0a1**. Локальная демонстрация обработчиков Telegram обозначается явно; полный выпуск и финальная репетиция остаются за условиями в [BLOCKERS.md](BLOCKERS.md).

До начала: выполните [установку](QUICKSTART.md), проверьте браузер, подготовьте [Android-раннер](NATIVE-RUNNER.md), соберите APK и выполните [парные демонстрации](DEMOS.md). Загрузки SDK и первая загрузка эмулятора входят в подготовку, а не в 13 минут выступления. Зафиксируйте текущие папки результатов. Если обязательный инструмент заблокирован, покажите блокировку и ограничьте заявленный объём.

| Время | Действие | Что зритель должен увидеть |
| --- | --- | --- |
| 0:00–1:00 | Объяснить проблему на примере ложного сохранения | Нажатие кнопки и надпись Saved ещё не подтверждают сохранённые данные |
| 1:00–3:00 | `autotest skill`, `doctor --probe-browser`, `validate examples/web.yaml`, `plan examples/web.yaml` | Инструкции для ИИ, работающий браузер, явный сценарий/ожидание/бюджет |
| 3:00–5:00 | `scripts/demo.py --module web --mode broken` | Реальный браузер нажимает Save; после открытия данные отсутствуют; oracle получает failed |
| 5:00–7:00 | `scripts/demo.py --module telegram --mode paired` | Реальный aiogram FSM: независимое состояние в исправном режиме и утечка между пользователями в дефектном; транспорт записывается локально |
| 7:00–9:30 | `scripts/demo.py --module android --mode paired --udid emulator-5554` | Подписанный APK, Appium, вход/сохранение/следующий экран; бэкенд подтверждает одну запись либо её отсутствие |
| 9:30–11:00 | Открыть актуальные `report.md`, `result.json`, `reproduction.json` | Требование, ожидаемое и наблюдаемое значение, run ID, версия/хеш APK и артефакты |
| 11:00–12:00 | `scripts/demo.py --module web --mode clean` | Тот же oracle проходит на исправной ветке fixture; режимы моделируют дефект и его устранение |
| 12:00–13:00 | Показать бенчмарк, CI и оставшиеся условия | 5/5 заданных дефектов и 0/5 ложных срабатываний относятся только к маленькому корпусу; live Telegram и независимый запуск ещё нужны |

Команды таблицы запускаются через `.venv/bin/autotest` и `.venv/bin/python scripts/demo.py` из корня исходного репозитория. Демо управляет своими тестовыми серверами; отдельный `autotest demo` одновременно запускать не нужно. Переход в чистый режим выбирает заранее реализованную исправную ветку, а не изображает автоматически написанное ИИ исправление.

Для полной презентации трёх реальных пользовательских платформ замените локальный Telegram-блок фактически выполненным `examples/telegram-live.yaml`, сохраните wire-доказательства и проведите независимый пробный запуск. До этого нельзя объявлять этапы 59–60, 98–100 завершёнными.

Для X подготовлены [тексты](X.md), [обложка](media/overview.png) и настоящие [исправный](media/android-clean.png)/[дефектный](media/android-broken.png) Android-экраны. [Manifest](media/manifest.json) связывает изображения с запусками. Снимки приложения не редактировались; демонстрационные данные синтетические. Публикация в X выполняется отдельно.
