# Материалы для X

Позиционирование: открытый alpha-скилл для coding agents, который превращает ожидания в исполнимые проверки и доказательства. Не заявляйте полный выпуск или замену всех тестировщиков: [обязательные условия](BLOCKERS.md) ещё открыты.

Ниже готовый тред. Для первого поста используйте [обложку](media/overview.png); для третьего — два настоящих Android-скриншота. Каждый текст помещается в 280 символов при обычном лимите. Это подготовленные материалы; в X ничего не опубликовано.

1. Сделал Autotest Skill: ИИ выбирает сценарий, реальные инструменты проверяют API, веб, обработчики Telegram и Android. На выходе — ожидание, факт и воспроизводимые артефакты. Открытая alpha 0.1.0a1: https://github.com/Zulut30/autotest-skill

2. Самый показательный баг: кнопка говорит «Saved», а данные не сохранены. Скилл открывает следующий экран и проверяет бэкенд. Нажатие кнопки, HTTP 200 или ноль выполненных тестов не становятся доказательством успеха.

3. Android проверен настоящим APK через Appium на API26: вход, роли, формы, отказ в разрешении, перезапуск, сбой API, клавиатура и сохранение. Исправная версия проходит; намеренное ложное сохранение обнаруживается тем же сценарием.

4. Бенчмарк: 5/5 заданных дефектов обнаружены, 0/5 ложных срабатываний на исправных парах. Это небольшой синтетический корпус, не оценка всех багов. Есть CI, приватные артефакты запусков, CLI, wheel и инструкции для агента.

5. Telegram сейчас проверяется через реальные aiogram-обработчики с записываемым транспортом. Для подтверждения настоящей доставки нужен отдельный тестовый бот и пользовательская сессия. Также впереди независимый первый запуск. Буду расширять корпус по реальным дефектам.

Альтернативный короткий пост на английском:

> Autotest Skill gives coding agents executable checks and evidence: API, real Chromium, local aiogram handlers and Android/Appium. Alpha: 5/5 seeded corpus defects detected, 0/5 clean-control false positives. Live Telegram remains a gate. https://github.com/Zulut30/autotest-skill
